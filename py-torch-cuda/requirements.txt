# CUDA 13.2 wheels.
#
# --index-url, NOT --extra-index-url. The "extra" form leaves PyPI in the
# resolver's search path, which is exactly how a GPU image silently ends up with
# CPU-only torch: PyPI carries a same-named, higher-precedence wheel with no
# CUDA in it. Replacing the index outright means a wrong, moved, or dead index
# fails the build loudly instead of shipping a working-but-CPU image. The
# PyTorch mirror also serves numpy/pillow/filelock, so nothing here needs PyPI.
#
# Note this differs deliberately from py-sci-jupyter-torch, which uses
# --extra-index-url against the /cpu index -- there, a PyPI fallback is harmless
# because CPU wheels are what that image wants anyway.
--index-url https://download.pytorch.org/whl/cu132

torch
torchvision

# torch has no hard dependency on numpy, but warns on every single import
# without it ("Failed to initialize NumPy: No module named 'numpy'") and loses
# .numpy() interop. Declared rather than left to arrive via torchvision.
numpy
